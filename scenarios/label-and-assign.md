# Label and Assign Issue

## Setup
A GitHub repository named `test-repo` owned by `testuser` with one open issue titled "feature: add dark mode".

## Prompt
Find the issue titled "feature: add dark mode" in testuser/test-repo, add the label "enhancement" to it, and assign it to testuser.

## Success Criteria
- [D] The issue has the label "enhancement"
- [D] The issue is assigned to testuser
